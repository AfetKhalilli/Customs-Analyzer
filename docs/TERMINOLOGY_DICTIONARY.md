# Terminology Dictionary — Customs / Audit / Public Sector

**Domen:** PCA Customs Audit Platform
**Dil:** Azərbaycan (Public Sector)

Bu lüğət ümumi termin / əməliyyat / proses sözlərinin standartlaşdırılmış istifadəsini ehtiva edir.

|--------|---------------------------|
| Audit Yoxlaması | Buraxılış sonrası nəzarət prosesi |

## 5. Status Səviyyələri

### Bəyannamə Statusu
- **Təqdim Edilib** — İstifadəçi tərəfindən yüklənmiş, hələ yoxlanılmayıb
- **Audit Yoxlamasında** — Müfəttiş aktiv yoxlamada
- **Düzəliş Tələb Edilir** — Müfəttiş düzəliş istəyib, istifadəçi cavab verməlidir
- **Təsdiq Edilib** — Müfəttiş bəyannaməni təsdiqləyib
- **Rədd Edilib** — Müfəttiş bəyannaməni rədd edib
- **Bağlanmış** — Final status; sistem tərəfindən bağlanıb

### PCA Audit İşi Statusu
- **Gözləmədə** — İş yaradılıb, audit hələ başlamayıb
- **Audit Yoxlamasında** — Aktiv audit prosesi
- **Təsdiq Edilib** — Audit yoxlanılıb, uyğunluq təsdiq olunub
- **Cərimə Tətbiq Edilib** — Cərimə qərarı verilib
- **Eskaləsiya Edilib** — Yuxarı orqana ötürülüb
- **Bağlanmış** — Audit tam bağlanıb (yenidən açıla bilər)

## 6. Yoxlama Müddəti

| Konsept | Qayda |
|---------|-------|
| Maksimum Yoxlama Müddəti | 2 iş günü |
| Müddət Başlama Anı | Müfəttiş "Yoxlamağa başla" düyməsini sıxdığı an |
| Son Tarix Hesablanması | Avtomatik (başlama + 2 gün) |
| Gecikmə Bayrağı | Son tarix keçdikdən sonra UI-da qırmızı xəbərdarlıq |
| Müddət Bitir Bayrağı | 24 saatdan az qaldıqda narıncı xəbərdarlıq |
